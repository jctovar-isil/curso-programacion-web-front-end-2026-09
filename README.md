# Programación Web Front End 2026

Repositorio de trabajo del curso **Programación Web Front End**, perteneciente al Diplomado de **Diseño y Desarrollo Web** de ISIL Educacion Ejecutiva.

## 📚 Descripción

Curso orientado al desarrollo de interfaces web modernas, responsive e interactivas, integrando **HTML, CSS y JavaScript** con sistemas de diseño y bibliotecas frontend.

La metodología del curso se basa principalmente en **Aprende Haciendo**, combinando conceptos aplicados y casos prácticos.

## 🎯 Objetivos

* Desarrollar interfaces web responsive.
* Aplicar HTML, CSS y JavaScript en proyectos frontend.
* Utilizar Flexbox y CSS Grid para construir layouts.
* Incorporar multimedia, formularios e interacción.
* Aplicar sistemas de diseño y componentes visuales.
* Utilizar bibliotecas frontend como Bootstrap, jQuery y React.
* Implementar websites en línea.

## 🚀 Proyecto final

El proyecto final consiste en desarrollar una **página web responsive**, aplicando los conocimientos adquiridos durante el curso y priorizando una buena experiencia de usuario.

La página deberá funcionar correctamente en diferentes dispositivos y será presentada mediante una demostración en vivo.
